File naming
Preview

If your choice uses Name, an Enter file name box appears beside the recording controls. The Save window opens with the completed filename already filled in.

Windows cannot use a slash in a filename, so the ending appears as .AM or .PM.

Mix profile

The selected mix profile will automatically restore its sources, names, volume, pan, master level, and MP3 quality whenever Tuesday Recorder starts.

Saving and recovery

The default is 10 seconds. Use the small arrows or type any value from 5 to 3,600 seconds. Pressing Stop creates one finished MP3 and removes its temporary checkpoints.
